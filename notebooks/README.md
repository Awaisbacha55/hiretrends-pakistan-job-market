# HireTrends Exploratory Notebooks

This directory contains Jupyter notebooks used for exploratory data analysis (EDA), prototype visualization, and statistical modeling.

## Directory Structure & Conventions

- `01_source_exploration.ipynb`: Initial testing of permitted data structures and schema mapping.
- `02_eda_salary_trends.ipynb`: Exploratory compensation distribution and correlation analysis.
- `03_skills_clustering.ipynb`: Skill co-occurrence matrices and cluster modeling.

## Status

Day 1 establishes project architecture and source compliance. Exploratory notebooks will be introduced starting from Day 3 to Day 5.
