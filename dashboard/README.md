# HireTrends Streamlit Dashboard

Interactive web dashboard for visualizing technology hiring trends across Pakistan.

## Architecture

The dashboard will be powered by Streamlit and Plotly, displaying:
- Top tech hubs and geographical hiring density.
- Most demanded programming languages, frameworks, and cloud platforms.
- Salary distributions across experience bands (entry, mid, senior, lead).
- Remote vs. hybrid vs. on-site market segmentation.

## Launching Dashboard (Planned for Day 6)

```powershell
.\venv\Scripts\Activate.ps1
streamlit run dashboard/app.py
```
